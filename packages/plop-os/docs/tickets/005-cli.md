# 005 — CLI: generators / candidates / run / sync

## Goal

Machine-friendly CLI for humans and agents: structured JSON stdout, non-zero exit on error, no interactive prompts.

## Depends on

- 003, 004

## Scope

- Package `bin`: `plop-os`.
- Commands:
  - `generators` — list scaffold generators (from plopfile) + sync IDs + discovery rule names
  - `candidates --rule <name> [--base <dir>]`
  - `run <scaffoldGenerator> --input '<json>'`
  - `sync [--id <syncId>] [--base <dir>]`
- Load plopfile from cwd (`plopfile.js|mjs|cjs`); require exported `plopOs`.
- Errors as JSON on stderr (or single JSON envelope); exit code ≠ 0.
- Interactive scaffold remains stock `plop` / documented coexistence.

## Out of scope

- Custom TUI; dry-run; watching.

## Acceptance

- [ ] Smoke tests or scripted invocations against fixture plopfile for each command.
- [ ] Invalid/missing input never blocks on stdin.
