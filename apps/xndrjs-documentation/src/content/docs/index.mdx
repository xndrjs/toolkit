## What is `xndrjs`

`xndrjs` is a TypeScript toolkit for building Full-Stack applications with explicit boundaries, composable semantics, and predictable data flow.

It is inspired by Clean Architecture and Domain-Driven Design, but it is not a framework built around those labels. The toolkit is a collection of small, focused libraries — each aimed at a concrete class of problem — that make good architectural habits easier to apply under normal delivery pressure.

## Why the name

The name `xndrjs` comes from `xndr`, a compact abbreviation of "Alexander": a reference to Alexander the Great and the legend of the Gordian knot.

Faced with an intricate knot, Alexander did not patiently untangle every loop. He cut through it. That image fits the project: `xndrjs` tries to give TypeScript systems a clean cut through complexity by making boundaries explicit, keeping domain meaning trustworthy, and choosing radical, original solutions where more usual conventions tend to keep the knot in place.
